# 튜토리얼

- 범위: 1형·2형 튜토리얼 판, 설정 화면의 "튜토리얼 다시 하기", 유형별 튜토리얼 완료 기록.
- 문구: 안내 문구는 모두 자리 채움 초안이다. 기획 담당이 정한다(6절). 결과 제목 `튜토리얼 끝!`, 버튼 `알겠어요`·`건너뛰기`, 실패 문구 `다시 해봐요`, 설정 버튼 `튜토리얼 다시 하기`만 확정이다.
- 수치: 새 혈당 수치를 만들지 않는다. 튜토리얼이 혈당을 움직일 때의 목표값은 이미 있는 설정 값에서 계산한다(4절). 연출 길이는 `Bootstrapper`의 Inspector 값이다(7절).
- 의학 정보: 안내 문구에는 지금 게임에 이미 있는 규칙만 쓴다. 새 의학 정보는 넣지 않는다.
- 바탕: [type-select.md](type-select.md), [hyper-event.md](hyper-event.md), [dev-scene.md](dev-scene.md) 6.11·9.13절

## 1. 목적

유형을 고른 아이가 처음 달리는 판에서 조작, 아이템, 장애물, 유형별 대처를 하나씩 직접 해 보며 익힌다. 안내가 끝나면 같은 판이 그대로 일반 주행으로 이어져, 배운 것을 바로 써 본다.

- 유형을 고르거나 바꾼 뒤 첫 판은 튜토리얼 판이다.
- 안내는 하나씩 나온다. 세계가 멈추고 설명이 뜨고, 아이가 `알겠어요`를 누르면 3-2-1 뒤에 직접 해 본다. 못 하면 `다시 해봐요` 뒤 같은 안내를 다시 한다. 해낼 때까지 넘어가지 않는다.
- 안내 구간이 끝나면 같은 판에서 일반 주행이 이어지고, 탈락하면 결과 화면에 `튜토리얼 끝!`만 나온다. 점수는 보여 주지 않는다.
- 튜토리얼 판은 기록 파일과 최고 점수에 남지 않는다. 보호자 리포트 지표에도 섞이지 않는다.
- 안내 구간에서는 탈락하지 않는다. 실패는 다시 해 보는 것으로만 이어진다.

하지 않는 것:
- 음성 안내, 그림 선택지, 손가락 그림 같은 실제 그래픽. 빈 틀과 문구까지만 만들었다.
- 2·3구간 내용 안내, 타이틀의 "이어하기"·"보호자" 버튼, 사운드 설정.
- 혈당이 정상인데 증상처럼 보이는 연출. 증상 연출은 실제 혈당을 따르므로, 튜토리얼이 혈당을 먼저 움직이고 연출은 그 결과로 나온다.

## 2. 언제 튜토리얼 판이 되나

```
처음 실행 → 유형 선택 → 타이틀 → [시작] → 튜토리얼 판
설정 → 유형 바꾸기 → 타이틀 → [시작] → 튜토리얼 판(바꾼 유형)
설정 → [튜토리얼 다시 하기] → 튜토리얼 판(지금 유형)
```

- `settings.json`에 두 값을 저장한다.
  - `tutorialPending`: 다음 `시작`이 튜토리얼 판인지. 유형을 고르거나 다른 유형으로 바꾸면 켠다. 안내 구간을 끝까지 마치거나 건너뛰면 끈다.
  - `tutorialDone[유형]`: 그 유형의 안내 구간을 끝까지 마친 적이 있는지. 한 번 켜지면 끄지 않는다.
- 설정에서 지금과 같은 유형을 다시 고르면 바꾼 것으로 보지 않는다.
- 안내 구간 도중 앱을 끄면 다음 `시작`에 튜토리얼을 처음부터 다시 한다. 어디까지 했는지는 저장하지 않는다.
- 결과 화면의 `다시 하기`는 일반 판(기록하는 판)을 연다.

### 2.1 건너뛰기
- 그 유형의 튜토리얼을 끝낸 적이 있으면 안내 구간의 모든 설명 창에 `건너뛰기`가 보인다. 처음이면 보이지 않는다.
- 누르면 튜토리얼 판을 닫고(기록 없음) 같은 유형의 일반 판을 새로 시작한다.
- 안내 구간 뒤 일반 주행 구간에는 건너뛰기가 없다.

## 3. 안내 한 번의 흐름

```
대상이 다가옴 → 세계 멈춤 → 설명 창 → [알겠어요] → 3-2-1 → 직접 해 봄 ─성공→ 다음 안내
                                                                    └실패→ "다시 해봐요" → 같은 안내 처음부터
```

- 장애물·음식·쉬는 곳은 캐릭터 앞 멈춤 거리(Inspector `Tutorial Stop Distance`)에 오면 멈춘다. 대처 이벤트는 발동하거나 단계가 바뀔 때 멈춘다.
- 설명 창과 3-2-1 동안에는 세 시계(세계, 혈당, 판단)가 모두 멈춘다. 앱을 백그라운드로 보냈다 돌아와도 설명 창은 그대로다.
- 설명 창은 `알겠어요`를 눌러야 닫힌다. 저절로 넘어가지 않는다.
- 3-2-1은 세계가 다시 달려야 하는 안내(장애물, 아이템, 1형 1단계, 2형 notice)에만 넣는다. 멈춘 패널에서 고르는 단계(1형 2~4단계, 고혈당 알리기, 2형 tell)는 설명 창을 닫으면 바로 패널이 나온다.
- 실패:
  - 장애물·아이템 안내: 대상을 놓치거나 부딪힘. 부딪혀도 탈락하지 않는다. 같은 대상을 다시 놓는다.
  - 대처 단계: 오답을 고름. 고른 답은 혈당에 반영하지 않고 오류로 기록하지도 않으며, 같은 단계를 다시 고른다.
- 안내 구간에는 제한 시간이 없다. 시간이 지나도 오류, 어른 대신 처리, 탈락이 일어나지 않는다.

## 4. 안내 순서

안내 구간에서는 무작위 장애물·간식·음식 줄·쉬는 곳을 놓지 않는다. 각 안내가 자기 대상만 놓는다.

### 4.1 공통 (두 유형)

| 순서 | 대상 | 놓는 방식 | 성공 |
| --- | --- | --- | --- |
| 1 | 왼쪽 | 캐릭터 바로 왼쪽 레인만 비우고 나머지 두 레인에 벽(`LaneBlock`). 가운데에서 시작하면 가운데·오른쪽이 막힌다. 캐릭터가 왼쪽 끝이면 가운데를 비운다 | 부딪히지 않고 지나감 |
| 2 | 오른쪽 | 캐릭터 바로 오른쪽 레인만 비우고 나머지 두 레인에 벽. 1번을 마쳐 왼쪽에 있으면 왼쪽·오른쪽이 막혀 가운데로 옮긴다. 캐릭터가 오른쪽 끝이면 가운데를 비운다 | 같음 |
| 3 | 점프 | 세 레인 모두 바닥 장애물(`LowObstacle`) | 같음 |
| 4 | 슬라이드 | 세 레인 모두 위 장애물(`HighObstacle`) | 같음 |
| 5 | 아이템 | 1형: 트랙 간식 하나(간식 설정의 첫 간식, 캐릭터와 다른 레인). 2형: 음식 줄 하나 | 먹음 |

- 장애물 그래픽이 맵마다 바뀌어도 종류(`LowObstacle`, `LaneBlock`, `HighObstacle`)는 그대로다. 안내가 종류로 대상을 고른다.

### 4.2 1형 대처

| 순서 | 대상 | 성공 |
| --- | --- | --- |
| 6 | 저혈당 1단계 위험 인지 | 측정기를 누름 |
| 7 | 2단계 대응 선택 | 빠른 당을 고름 |
| 8 | 3단계 처치량 | 적정량을 고름 |
| 9 | 4단계 ① 재측정 | 재측정을 고름 |
| 10 | 4단계 ② 알리기 | 어른에게 알리기를 고름 |
| 11 | 고혈당 알리기 | 어른에게 알리기를 고름 |

- 6번: 튜토리얼이 실제 혈당을 `(elimination.glucoseLow + glucose.hypoThreshold) / 2`까지 고르게 내린다. 지금 규칙대로 저혈당이 발동하고 흔들림도 실제 혈당을 따라 나온다. 표시 혈당 지연은 그대로다.
- 7~10번은 지금 4단계 패널을 그대로 쓴다. 2·3단계와 4단계 ①에서 `어른에게 알리기`를 누르면 오답이라 `다시 해봐요`다. 고른 빠른 당과 양은 지금처럼 혈당에 반영한다.
- 4단계를 마치면 지금처럼 재개 카운트다운과 유예가 이어진다.
- 11번: 튜토리얼이 실제 혈당을 `(glucose.hyperThreshold + elimination.glucoseHigh) / 2`까지 올린다.

### 4.3 2형 대처

| 순서 | 대상 | 성공 |
| --- | --- | --- |
| 5 | choose 음식 줄 | 두 음식 중 하나를 먹음. 빈 레인으로 지나가면 `다시 해봐요` |
| 6 | move 쉬는 곳 | 쉬기 시작함 |
| 7 | notice 높음 → tell | 신호가 처음 뜰 때 설명, 3-2-1로 다시 달려 신호를 봄, tell이 열리면 설명을 한 번 더. 어른에게 알리기를 고름 |
| 8 | notice 낮음 → tell | 7번과 같음. 알리면 지금처럼 어른이 빠른 당을 건넨다 |

- 7번 목표값은 `(glucose.hyperThreshold + elimination.glucoseHigh) / 2`, 8번은 `(elimination.glucoseLow + glucose.hypoThreshold) / 2`다(2형 설정).
- tell의 `계속 달리기`, `주스 마시기`는 오답이라 `다시 해봐요`다. 주스 1회분은 혈당에 반영하지 않는다.
- 기본 하강 때문에 목표값까지 가도 발동 기준 밖으로 밀리면 튜토리얼이 다시 옮긴다. 대상 이벤트는 끝내 발동한다.

### 4.4 안내 구간 끝

- 마지막 안내를 마치면 실제 혈당을 `glucose.initial`로 되돌리고(설명 창이 떠 있는 동안이라 튀어 보이지 않는다) 마무리 설명을 띄운다. 1형은 표시 혈당도 함께 맞춘다.
- 이때 `tutorialDone[지금 유형]`을 켜고 `tutorialPending`을 끈다.
- 3-2-1 뒤 일반 주행이 이어진다. 무작위 배치, 제한 시간, 오류 처리, 탈락, 무작위 이벤트, 속도 증가가 모두 보통 판과 같다. 기록과 최고 점수만 여전히 없다.
- 안내 구간 동안 막는 것: 튜토리얼이 일으키지 않은 저혈당·고혈당·2형 notice 발동, 급하강, 혈당 범위 탈락, 장애물 탈락.
- 거리와 구간 경계는 지금처럼 늘고 넘는다. 안내 구간 중 2구간 장면에 들어가도 그대로 진행한다.

## 5. 기록과 결과

- 튜토리얼 판은 기록 파일을 만들지 않는다. 도메인 이벤트는 지금처럼 나가지만 기록하지 않는 주행으로 연다.
- 최고 점수를 읽지도 저장하지도 않는다.
- 결과 화면: 제목 `튜토리얼 끝!`만 보이고 요약 줄은 없다. 버튼은 지금과 같다(`다시 하기`는 일반 판, `타이틀로`).
- 주행 중 HUD의 점수 표시는 지금 그대로다.

## 6. 기획 담당이 고칠 문구

`Assets/_Project/Scripts/Presentation/TutorialText.cs`에 있다. 지금은 초안이다. 치료·진단 주장, "나쁜 음식", 먹으면 힘들어진다는 표현, "죽음/생존" 표현은 쓰지 않는다. 증상 이름(떨림, 식은땀 등)은 의학 출처 확인 전에 쓰지 않는다.

| 안내 | 유형 | 초안 |
| --- | --- | --- |
| 왼쪽 | 공통 | 왼쪽으로 밀어서 피해요 |
| 오른쪽 | 공통 | 오른쪽으로 밀어서 피해요 |
| 점프 | 공통 | 위로 밀면 뛰어넘어요 |
| 슬라이드 | 공통 | 아래로 밀면 미끄러져요 |
| 간식 | 1형 | 간식이 있는 줄로 가면 먹어요. 먹으면 혈당이 올라요 |
| 음식 줄 | 2형 | 달리면서 먹을 음식을 골라요. 먹으면 혈당이 올라요 |
| 쉬는 곳 | 2형 | 여기로 가면 쉴 수 있어요. 쉬는 동안은 혈당이 덜 내려가요 |
| 1단계 위험 인지 | 1형 | 화면이 흔들리면 몸이 보내는 신호예요. 측정기를 눌러요 |
| 2단계 대응 선택 | 1형 | 빠른 당을 골라요 |
| 3단계 처치량 | 1형 | 알맞은 양을 골라요 |
| 4단계 ① 재측정 | 1형 | 먹은 뒤에는 다시 재 봐요 |
| 4단계 ② 알리기 | 1형 | 어른에게 알려요 |
| 고혈당 알리기 | 1형 | 혈당이 높을 때도 어른에게 알려요 |
| notice 높음 | 2형 | 목이 마르고 화장실에 가고 싶은 신호가 보이면 어른에게 알려요 |
| notice 낮음 | 2형 | 힘이 없는 신호가 보이면 어른에게 알려요 |
| tell(높음·낮음) | 2형 | 어른에게 알리기를 골라요 |
| 마무리 | 공통 | 이제 혼자 달려 봐요! |

- "몸이 보내는 신호"는 지금 게임 규칙(흔들림은 실제 혈당을 따른다)을 말할 뿐 증상의 의학 설명이 아니다.
- 2형 notice 문구의 신호 이름은 이미 있는 연출(갈증 말풍선, 화장실 아이콘, 지친 모습)을 가리킨다. 의학 출처와 함께 고친다.
- "쉬는 동안은 혈당이 덜 내려가요"는 지금 게임 규칙(쉬는 동안 달리기 하강이 멈춘다)이다.

## 7. 모듈과 Inspector 값

| 모듈 | 계층 | 하는 일 |

## 8. 팀원별로 알아야 할 것

### 공통
- 유형을 고르거나 바꾼 뒤 첫 판은 튜토리얼 판이다.
- 튜토리얼 판은 기록·최고 점수에 남지 않는다.
- 설정 화면에 `튜토리얼 다시 하기`가 있다.
- 확인 방법은 [dev-scene.md](dev-scene.md) 9.13절이다.

### 팀원1(캐릭터)
- 튜토리얼에서 캐릭터는 지금과 같이 움직인다. 새로 할 일은 없다.
- 설명 창이 떠 있는 동안 세계가 멈추므로 애니메이션도 멈춰 보여야 한다(`worldDt` 0).

### 팀원2(월드)
- 장애물 종류 3개(`LowObstacle` 점프, `LaneBlock` 옆으로, `HighObstacle` 슬라이드)는 맵마다 그림이 바뀌어도 종류를 유지한다. 튜토리얼이 종류로 대상을 고른다.

### 팀원3(화면)
- `Screen/TutorialPromptView` 채우기: 화면 전체를 덮어 아래 터치를 막는 설명 창, 문구, 그림 자리, `알겠어요`·`건너뛰기` 버튼, `다시 해봐요` 문구. 보이고 숨기는 방식(`root`와 `retryText`를 따로 켜고 끔)은 그대로 둔다.
- `retryText`는 `root`의 자식이 아니어야 한다. `root`는 설명 창이 없을 때 꺼지므로 그 안에 두면 `다시 해봐요`가 보이지 않는다([dev-scene.md](dev-scene.md) 6.11절).
- `Screen/SettingsView`에 `tutorialButton`(`튜토리얼 다시 하기`)이 추가됐다.
- 튜토리얼 결과 화면은 제목 `튜토리얼 끝!`만 보인다.
