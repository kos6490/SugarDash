# 1형·2형 주행 확장 방향

- 상태: 세부 규칙은 단계별 설계 문서에서 정한다(9절).
- 수치: 이 문서에 나오는 새 수치는 모두 PLACEHOLDER(`null`)다. 담당자가 정하기 전까지 임의의 값으로 채우지 않는다.
- 의학 정보: 2형 신호, 음식·운동·수면의 혈당 영향은 세 출처(대한당뇨병학회 진료지침, ISPAD, ADA)로 확인한 뒤에 넣는다. 확인 전에는 게임 규칙으로 쓰지 않는다.
- 바탕: `docs/glucose-model.md`, `docs/hyper-event.md`, `docs/roadmap.md`

## 1. 목적

지금까지는 제1형 당뇨병 아동만 대상으로 했다. 여기에 제2형 당뇨병 아동을 더한다. 게임을 시작할 때 유형을 고르고, 유형마다 다른 대처법으로 다른 게임을 한다. 러너 코어처럼 두 유형이 같이 쓸 수 있는 부분은 다시 쓴다.

유형과 상관없이 식사, 운동, 수면, 도움 요청, 혈당 관리 습관 같은 공통 학습도 주행 안에 녹인다.

### 성공 기준
- 판이 끝난 뒤 아이가 "재밌다", "혈당 관리가 중요하다"를 함께 느낀다.

### 목표
- 시작할 때 1형·2형을 고른다. 고른 유형의 대처법대로 게임이 진행된다.
- 2형 대처 4단계: choose → move → notice → tell(4절).
- 2형은 혈당 상태가 캐릭터 그래픽에 나타난다(5절).
- 트랙 아이템을 간식에서 아이들이 아는 음식 전반으로 넓힌다(6절).
- 두 유형 모두 1구간(기본 익히기) → 2구간(조건별 판단) → 3구간(복합 상황) 틀을 쓴다. 2·3구간은 생활 환경 맵에서 진행한다(8절).

### 반목표 (하지 않을 것)
- 혈당이 높을 때 캐릭터 체형을 바꾸지 않는다(부풀어 뚱뚱해지는 연출 등). 왜: 혈당이 오른다고 그 자리에서 살이 찌지 않으므로 의학적으로 틀린 정보다. 또 2형 아동이 겪기 쉬운 체중 놀림을 게임이 가르치게 된다.
- 음식을 "나쁜 음식"으로 부르거나, 하나 먹었다고 바로 캐릭터가 힘들어지게 하지 않는다. 왜: 음식 죄책감과 섭식 문제로 이어질 수 있다. 금지 음식보다 양과 균형을 가르친다.
- "아파한다"가 아니라 "지쳐 보인다"로 연출한다.
- 혈당은 정상인데 증상처럼 보이는 가짜 신호를 넣지 않는다(1형과 같은 규칙). 2형 notice 연출은 실제 혈당이 기준을 넘었을 때만 나온다.
- 화면을 자주 멈추지 않는다(7절).

## 2. 유형 선택

- 게임을 시작할 때 1형·2형 중 하나를 고른다. 처음 실행하면 유형 선택 화면이 먼저 뜨고, 고른 유형은 저장되어 다음부터는 타이틀 화면이 먼저 뜬다. 유형은 설정 화면에서 바꾼다. 화면 흐름의 세부는 `docs/type-select.md` 2절에 있다.
- 고른 유형은 한 판 동안 바뀌지 않는다.

## 4. 2형 대처 4단계

| 단계 | 언제 | 아이가 하는 것 | 결과 |
| --- | --- | --- | --- |
| choose | 트랙에 음료·음식 아이템이 나옴 | 레인으로 고른다. 예: 물 vs 탄산·주스 | 고른 것이 혈당에 반영된다. 틀려도 즉시 벌칙은 없고 누적된다 |
| move | 쉬는 구간(벤치, 게임기 등)이 나옴 | 계속 달리기 vs 앉아서 쉬기. 쉬는 곳은 한 레인에 있고 그 레인으로 들어가면 정해진 시간 동안 쉰다 | 쉬는 동안 달리기에 의한 혈당 하강이 멈춘다. 즉시 벌칙 없음. 지금 혈당이 높은지 낮은지에 따라 어느 쪽이 나은지가 달라져 정답을 하나로 정하지 않는다 |
| notice | choose·move가 쌓여 실제 혈당이 기준 이상(높음) 또는 기준 미만(낮음)으로 일정 시간 유지됨 | 신호를 본다. 주행은 계속된다 | 높음: 갈증 말풍선, 화장실 아이콘 깜빡임(개발용 표시), 캐릭터가 지쳐 보임. 낮음: 개발용 표시만 있고 신호 그림은 출처 확인 뒤 정한다. 지친 연출은 연출만이며 실제 속도·충돌·거리를 바꾸지 않는다 |
| tell | notice 직후 | 제한 시간 선택 UI에서 고른다 | "어른에게 알리기"(정답), "주스 마시기"(오답, 높음 쪽에만: 혈당 악화, `HY_JUICE`), "계속 달리기"(오답: 신호 무시, 높음 `HY_KEEP_RUNNING` / 낮음 `LO_KEEP_RUNNING`). 시간 초과는 `HY_TIMEOUT`, `LO_TIMEOUT`. 낮음 쪽은 알리면 어른이 빠른 당을 건넨다 |

- choose·move는 주행을 멈추지 않는다. tell만 세계를 멈춘다(7절).
- tell은 1형 고혈당 알리기(`docs/hyper-event.md`)의 선택 패널과 흐름을 다시 쓴다. 정답이면 재개, 오답·시간 초과면 오류 공통 처리(위급 연출, 알리기 대기, 못 하면 탈락). 탈락 규칙은 1형과 같다.
- 2형에는 측정기, 표시 혈당 지연, 게이지 경고, 급하강, 저혈당 4단계, 화면 흔들림이 없다. 혈당바는 실제 혈당을 보여 준다.
- 먹는 행동과 쉬는 행동에는 점수와 정답·오답 판정이 없다.
- 자세한 규칙은 `docs/type-select.md` 4~5절에 있다.
- 갈증, 잦은 소변, 피로가 고혈당 신호로 적합한지는 출처로 확인한 뒤 확정한다.
- 정할 것: 기준 혈당과 유지 시간 같은 수치(10절).

## 5. 캐릭터 상태 연출 (2형)

- 실제 혈당 상태를 캐릭터에 나타낸다: 지친 표정, 느려진 걸음, 처진 자세.
- 체형은 바꾸지 않는다(1절 반목표).
- 아이가 느낄 것: "지금 내 몸이 힘들다는 신호를 알아채자."
- 연출 종류와 시작 혈당은 출처 확인 뒤 정한다.

## 6. 트랙 음식 (두 유형 공통)

- 트랙 아이템이 간식일 필요는 없다. 햄버거, 치킨, 과일, 물, 주스처럼 아이들이 아는 음식이 나온다.
- 먹으면 음식마다 정해진 만큼 혈당에 반영된다. 음식 목록과 그래픽은 공유하고, 혈당 영향 값은 유형별 설정에서 받는다(제안: 지금의 snack 설정을 음식 목록으로 넓힌다).
- 1형 저혈당 대처의 빠른 당·느린 당도 이 목록에서 가져온다.
- 음식마다 오르는 속도가 다르다는 점(예: 지방이 많은 음식과 단 음료)은 출처 확인 뒤 반영한다. 그전까지 값은 PLACEHOLDER다.
- 짧은 시간에 몰아서 먹거나 단 음료가 겹칠 때 혈당이 오르도록 한다. 하나 먹었다고 바로 지치지 않는다.
- 1형 트랙에는 저혈당 대처에 쓰는 간식(빠른 당: 주스·탄산음료, 느린 당: 크래커·사과)만 나온다. 치킨·피자·햄버거 같은 일반 음식은 2형 트랙에만 나온다(2026-11-09). 왜: 게임은 인슐린 투여를 다루지 않으므로, 1형에서 일반 음식이 혈당을 그대로 올리면 "1형은 밥을 먹으면 혈당이 계속 오른다"는 틀린 그림을 배운다. 음식 목록과 그래픽은 그대로 공유하고, 유형마다 트랙에 나오는 음식이 다르다. 등급은 [food-evidence.md](food-evidence.md).

## 7. 러너다움을 지키는 원칙 (제안, 단계별 설계 때 확인)

교육용이지만 러너의 재미는 멈추지 않는 흐름과 순간 판단에서 나온다. 멈추는 요소가 늘면 달리기 연출을 붙인 퀴즈가 된다.

1. 고르는 것은 최대한 달리면서 한다. 레인 선택이 곧 판단이다(choose, move, 음식).
2. 세계를 멈추는 것은 어른이 필요한 위급한 순간만 한다(1형 저혈당 2~4단계, 1형 고혈당 알리기, 2형 tell). 멈춤이 드물어야 "중요한 순간"이라는 신호가 된다.
3. 수면은 메뉴가 아니라 짧은 장면 전환이다. 밤에 한 번 고르고 바로 아침으로 넘어간다.
4. 좋은 습관은 콤보, 속도감, 맵 연출 같은 재미로 돌려준다. 단 먹는 행동 자체에는 점수를 주지 않는다(1형 규칙과 같다).
5. 맵 특성은 장애물과 레인 구성으로 보여 준다(예: 운동장의 축구공, 놀이터의 미끄럼틀).

## 8. 구간, 맵, 하루 흐름 (두 유형 공통)

| 구간 | 내용 | 맵 |
| --- | --- | --- |
| 1구간 신호 인식 | 지금까지 만든 것. 튜토리얼 성격으로 유형별 대처의 기본을 익힌다 | 하나 |
| 2구간 조건별 판단 | 맵마다 조건이 달라 판단이 달라진다 | 생활 환경 맵 여러 개 |
| 3구간 복합 상황 | 2구간의 조건이 겹쳐 나온다 | 생활 환경 맵 여러 개 |

- 한 판은 탈락하기 전까지 계속 이어진다. 구간은 지금처럼 누적 거리로 바뀐다.
- 생활 환경 맵: 2구간은 학교 운동장(아침) → 놀이터(오후) → 가족 나들이(저녁) → 집(밤, 짧은 장면)으로 이어진다. 맵 하나가 하루의 한 때다. 맵별 특성(예: 운동장의 체육 시간, 놀이터의 쉬는 곳, 나들이의 외식 음식)은 2-B에서 출처 확인 뒤 정한다.
- 하루 흐름: 장면이 누적 거리로 바뀌고, 집 장면이 끝나면 짧은 암전(수면 전환) 뒤 다음 날 아침이 된다. 2구간 하루 한 번 뒤 3구간 하루가 끝없이 되풀이된다([section3.md](section3.md)). 집 장면에는 트랙 물체가 나오지 않는다. 상세는 [section2.md](section2.md).
- 맵마다 설정 덮어쓰기(혈당 하강, 급하강 확률, 트랙 간식·음식·쉬는 곳 간격)를 둘 수 있다. 빌드 설정에서는 출처 확인 전까지 비워 둔다.
- 혈당 관리 습관: 1형은 하루의 정해진 때(예: 운동 전, 자기 전)에 혈당을 재 보는 순간을 넣는 것을 2-B 후보로 둔다. 2형은 측정기가 없어 넣지 않았고, 출처를 찾아 정한다.
- 운동·수면이 유형별로 혈당에 주는 영향은 출처 확인 뒤 정한다.
- 1구간은 맵을 나누지 않고 지금처럼 단순하게 둔다. 하루 흐름은 2·3구간에서 돌아간다.

## 9. 진행 순서

각 단계는 설계 문서를 만들고 승인받은 뒤 구현한다. 퀴즈 관문보다 구간별 주행을 먼저 한다.

1. 유형 선택 + 2형 1구간: 시작 화면 선택, 2형 choose·move·notice·tell, 지친 캐릭터 연출, 음식 아이템 최소 확장
2. 2구간 + 생활 환경 맵 + 하루 흐름: 두 유형 공통 틀 위에 유형별 조건 이벤트
3. 3구간 복합 상황
4. 그 뒤: 퀴즈 관문 등 2순위

## 10. 남은 결정 사항

2형 1구간의 규칙(실제 혈당만 보여 주기, 저혈당도 notice → tell, 오류 코드, 오답 뒤 처리, 탈락 규칙, 유형별 최고 점수, 유형 선택 화면 흐름)은 정해졌다(`docs/type-select.md`). 아래가 남았다.

| 정할 것 | 분야 |
| --- | --- |
| 2형 모든 수치: 혈당 시작값, 고혈당·저혈당 기준과 유지 시간, 음식·쉬기·운동 반영량, tell 제한 시간. 정함: [glucose-evidence.md](glucose-evidence.md), [game-values.md](game-values.md) | 결정, 의학 |
| 2형 notice 신호(갈증, 화장실, 피로)와 캐릭터 연출의 출처. 정함: [notice-evidence.md](notice-evidence.md) | 의학 |
| 음식 목록, 음식별 혈당 영향과 출처, 1형 주행에서 일반 음식 처리. 정함: [food-evidence.md](food-evidence.md), 6절 | 결정, 의학 |
| 운동·수면의 유형별 혈당 영향과 출처 | 의학 |
